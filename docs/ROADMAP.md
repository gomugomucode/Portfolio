# Long-Term Product & Engineering Roadmap

Future Scalability Milestones and Technological Extension Roadmap.

---

## 🗺️ Roadmap Phases

### Phase 1: High-Conversion Recruiter & SEO Foundations (Completed ✅)
- Pre-rendering static HTML for 18 routes (`prerender.mjs`).
- Complete Schema.org JSON-LD structured data.
- Automated Medium RSS feed parsing and 6-hour browser caching.
- Zod form validation & sliding-window rate limiting.
- Resilient API client with timeout and exponential backoff.

### Phase 2: Live Integrations & Advanced Intelligence (Current)
- GitHub REST API live repository metadata integration.
- Visitor browsing progress memory and category recommendation engine.
- Multi-domain fuzzy search indexer across projects, writing, and skills.

### Phase 3: Headless CMS & Supabase Backend (Future Extension)
- Supabase PostgreSQL persistence for dynamic comments and project likes.
- Sanity or Contentful Headless CMS sync.
- Gemini RAG semantic search and portfolio assistant capabilities.
