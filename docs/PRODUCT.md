# Product & Strategy Specification

Executive Overview, Target Audience Persona Specs, and Value Proposition Strategy.

---

## 1. Primary Objectives & Personas

1. **Recruiters & Engineering Hiring Managers**:
   - **Needs**: Fast verification of technical stack, code quality, impact metrics, open-source repositories, downloadable resumes, and contact availability.
   - **Optimization**: Clean executive summaries, project architecture diagrams, verified GitHub links, and sub-second page loads.

2. **Technical Peers & Engineering Leads**:
   - **Needs**: Deep architectural case studies, live previews, Medium technical writing, type safety, and clean software patterns.
   - **Optimization**: Full Schema.org metadata, technical articles, and GitHub integration.

---

## 2. Key Product Features

- **Decoupled Blog & Medium Integration**: Automatic 6-hour caching, XML parsing, and clean article preview pages.
- **Visitor Browsing Memory**: Tracks recently viewed projects and reading progress via browser `localStorage`.
- **Global Search Engine**: Fast multi-domain fuzzy search across projects, writing, skills, and pages.
