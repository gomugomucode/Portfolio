## 🎯 Conversion Flow Architecture

Every page end-state is engineered to present recruiters, engineering managers, and clients with clear, high-intent next steps:

| Page | Target Action / Primary CTA | Secondary CTA |
| :--- | :--- | :--- |
| **Home (`/`)** | `Explore Projects →` | `Get in Touch` |
| **About (`/about`)** | `For Recruiters →` | `Direct Email` |
| **Projects (`/projects`)** | `View Case Study` | `View Source Code` |
| **Project Detail (`/project/:id`)** | `View Architecture & Code` | `Contact Me` |
| **Blog (`/blog`)** | `Read Article Preview` | `Read Full on Medium →` |
| **Article Preview (`/blog/:slug`)** | `Continue Reading on Medium →` | `Back to Articles` |
| **For Recruiters (`/for-recruiters`)** | `Download Resume (PDF)` | `Schedule Interview` |
| **Contact (`/contact`)** | `Send Message` | `contact@anupambaral.com.np` |
